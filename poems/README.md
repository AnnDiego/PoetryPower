# poems/

Local folder for poem files and poem-visualizer markdown. This repository does not track poems.

The visualizer, analyzer, and mad-lib tools look here when a path is given by filename, and the visualizer writes pasted-poem reports into this folder when it exists. Point the tools at a file outside the repo if you keep poems somewhere else. Output written next to a poem, or into this folder, stays on your machine.

Only this README is tracked. Do not put poem text in this file, and do not force-add anything else under `poems/`.
